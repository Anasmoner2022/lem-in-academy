GO ONLY · STANDARD LIBRARY

Optional Go visualizer brief

Build a standard-library Go program that consumes a complete lem-in transcript on stdin and writes an animated ant-farm GIF, room legend and text replay. Validate the stream independently before rendering it.

./lem-in ant-farm.txt | ./visualizer

Default outputs are farm.gif, legend.txt and replay.txt. The GIF shows rooms/tunnels from coordinates and moves ants along their actual tunnels, retaining waits and terminal arrivals. Negative, coincident and zero-span coordinates must be handled safely. Text output preserves arbitrary valid names and every ant's identity.

Preparation is P13 · Replay Stream Decoder, then P14 · Go Raster and GIF Studio. Integration is V01 · Optional Ant-Farm GIF Visualizer.

Why GIF

Go's standard library includes raster images and GIF encoding, making an animated file feasible without browser programming or third-party graphics. A viewer displays the output; viewer playback timing can vary. The academy requires decode-back metadata tests plus viewed motion. 3D appears as an audit extra, outside this bonus's required 2D scope.

Readiness gate

Core L01 reviewed first; valid/invalid pipeline tests; immutable replay; safe coordinate transform; frame/pixel budgets; output collision/cleanup tests; no trails; correct final state; accurate legend/replay. A legal but slow transcript may be rendered, but the visualizer must not describe it as optimal.

Learn it. Build it. Explain it.
