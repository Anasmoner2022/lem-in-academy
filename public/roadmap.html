The staged roadmap

Learn the skill, build the artifact, demonstrate its exit gate, then integrate. There are 12 required preparation projects before lem-in and two optional preparation projects after it. The order follows actual dependencies; the visualizer never blocks core completion.

Planning, not a deadline: required prep is 142 focused hours; core integration is 40, totaling 182 before review. Allow another 25–50% for reading, debugging and review: about 228–273 hours. At 20 focused hours per week, plan roughly 12–14 weeks. The complete optional visualizer adds 42 base hours, or about 53–63 with review. Learner completion is unassessed.

STAGE 01 · 32 HOURS

Go and colony data

  1. P01 · Go Field Notebook — 8h. Learn types, modules, returned errors and tests.
  2. P02 · Bounded File Reader — 10h. Handle files, EOF, line endings and read limits.
  3. P03 · Colony Grammar State Machine — 14h. Validate the actual language and preserve accepted echo.

Readiness gate: demonstrate the grammar mutation table, bounded-reader fault tests and no accepted partial model. A valid parse need not have a route yet.

STAGE 02 · 30 HOURS

Graphs and turn safety

  1. P04 · Undirected Graph Inventory — 8h. Stable identity, adjacency, components and ordinary cycles.
  2. P05 · Queue and BFS Route Finder — 10h. Distance, parents and unreachable targets.
  3. P06 · Turn Safety Simulator — 12h. Independent atomic validation of concurrent movement.

Readiness gate: a pipeline into a vacated room passes; stationary-room collisions and shared-tunnel swaps fail. Prove BFS distance for one ant and explain why it is insufficient for all ants.

STAGE 03 · 56 HOURS

Exact optimization

  1. P07 · Traffic and Ant Allocation Lab — 8h. Throughput, makespan and a greedy counterexample.
  2. P08 · Residual Flow Workbench — 14h. Reverse arcs, conservation, integrality and cuts.
  3. P09 · Capacity Through Time — 16h. Room splits, waiting and shared tunnel-time bottlenecks.
  4. P10 · Exact Deadline Planner — 18h. Deadline search, extraction, ant IDs and proof.

Readiness gate: show both directions of the schedule/flow correspondence and feasibility at T plus a lower-bound witness at T-1. Resource refusal must never become false in a deadline probe.

STAGE 04 · 24 HOURS

Verification and release

  1. P11 · Adversarial Validator and Tiny Oracle — 14h. Transcript checks, occupancy-state search and differential evidence.
  2. P12 · Deterministic and Bounded Release Lab — 10h. Checked budgets, stable streams and reproducibility.

Readiness gate: complete the 3294-case small-graph campaign, report every budget skip and catch targeted transcript mutations. Compilation of a TODO starter does not satisfy this gate.

INTEGRATION · 40 HOURS

Build lem-in

L01 · Full lem-in guide →

Bring the prepared components into one CLI. Review the assignment brief, academy policies and requirement coverage. Produce a minimum-turn schedule, independent replay evidence, an exactness argument and measured source-audit compatibility results.

Readiness gate: all required behavior, enabled solution tests, exactness proof, tiny evidence and process/resource contract pass instructor review. The hub does not set completion automatically.

OPTIONAL STAGE 05 · 22 HOURS

Prepare the visualizer

  1. P13 · Replay Stream Decoder — 10h. Validated streams and immutable snapshots.
  2. P14 · Go Raster and GIF Studio — 12h. Coordinates, pixels, palettes and GIF timing.

Readiness gate: decoder rejects corrupt/truncated streams; rendered GIF decodes back with correct frames, delays and independent pixel storage.

OPTIONAL INTEGRATION · 20 HOURS

Build the Go GIF visualizer

V01 · Optional visualizer guide →

Consume solver stdout and generate farm.gif plus legend/replay text using only standard Go packages. Validate the real pipeline, safe output handling and viewed motion. A 3D display is outside this academy bonus's required scope.

Team and scheduling guidance

Estimates assume an individual with basic programming experience, regular review and no prior Go/graph/flow knowledge. Pairing can help discussion but does not halve concept time. Add time for a learner who needs the prerequisite bridge; allow strong learners to challenge a preparation gate with an equivalent working artifact and explanation. Team size is a local teaching decision, not an upstream requirement.

Learn it. Build it. Explain it.
