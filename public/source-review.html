Interpretations verified against examples

  • The subject requires a file argument; an audit question calls it standard input. The curriculum follows the file-based executable usage and reserves stdin for the visualizer.
  • Unknown commands are ignored according to the subject. The audit's “only commands” language is interpreted as only start/end having semantic effects, rather than rejection of unknown directives.
  • Usage Example 2 demonstrates entering a room vacated during the same turn. The academy publishes batch departure/arrival semantics explicitly.
  • Each tunnel's once-per-turn rule applies even when both endpoints are unlimited-capacity terminals.
  • The subject's self-link error discussion and badexample01 support self-link rejection. Ordinary multiroom cycles are valid graph structures; safe traversal handles them.
  • Displayed audit schedules include formatting typos and need not be a unique optimum. Use source example data, legal-movement checks and exactness evidence; do not copy a displayed schedule as the complete test oracle.
