A build, not a solution dump

Each guide has exact reading, a focused refresher, an explicit contract, unfinished downloadable Go code, component chapters, verification gates and discussion prompts. Students supply the algorithms.

Exactness is part of correctness

The planner searches deadlines with time-expanded integral flow. The track includes a separate movement checker and a tiny exhaustive oracle to challenge optimality claims.
