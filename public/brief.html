Lem-in assignment brief

Build a Go CLI named lem-in that reads an ant colony from a file argument and brings every numbered ant from start to end in the fewest turns. Preserve the original assignment separately from the academy's explicit implementation policies.

Open the full guided assignment → Read the original upstream brief

Inputs and outputs

A colony contains a positive ant count, room records name x y, terminal directives ##start/##end and undirected name-name tunnel records. Room names are not assumed numeric or ordered. On success, print the accepted colony, one blank separator and one movement line per turn using L<number>-<destination> tokens. Display only ants that move.

Constraints that determine the algorithm

All ants start together. Ordinary rooms hold one ant; terminal rooms can hold many. Every tunnel is a shared undirected resource usable once per turn, and every ant can move through only one tunnel per turn. A shortest path for one ant can be a poor multi-ant choice. An exact solution must optimize final arrival time while avoiding both room collisions and tunnel reuse.

Errors and edge cases

Handle malformed counts/records, missing or repeated terminals, duplicate rooms/tunnels, unknown endpoints, invalid integers, self-links and no route deliberately with the required invalid-data prefix. Ordinary graph cycles and irrelevant disconnected rooms require safe traversal. Ignore unknown commands. The academy contract resolves whitespace, echo, integer spelling, hyphen ambiguity, turn ordering, streams/exits and resource boundaries.

Submission

  • Go source using only standard packages, build/run instructions and meaningful tests.
  • A correctness argument for the exact planning method, including capacities, waits, ant extraction and minimum deadline.
  • An independent transcript/movement validator and tiny-instance optimality evidence.
  • Adversarial fixtures, deterministic output checks, complexity/resource notes and measured audit example results.

Optional continuation

After core readiness, complete P13/P14 and the Go GIF visualizer bonus. Coordinates become display data there. The bonus does not replace the required CLI or optimality proof.
