Reproducible build and publication

The authoring source, Go builder, unfinished starter modules and generated public directory belong to this standalone hub. Students need Go for their exercises; publication needs no package-manager installation.

Build locally

go run ./cmd/hub build
go run ./cmd/hub check -scaffolds
go test ./...
go vet ./...
go run ./cmd/hub serve

Run at the academy root. The preview serves http://127.0.0.1:8086. The build reads curriculum/projects, pages and coverage data, writes every complete guide in order, formats Go starters, creates deterministic ZIP downloads and copies static assets/sources/evidence into public. The check command validates generated HTML structure, local links/anchors, preparation order, guide counts, coverage IDs and optional nested starter module compilation/vet.

Reproducibility and editing

Edit curriculum data or the shared assets, then rebuild. Do not edit generated public pages or the supplied starter copies after beginning student work. ZIP timestamps and ordering are fixed. The generated site has no runtime API, browser script or external font dependency. Evidence files record the particular validation run and may change when checks are rerun.

Vercel-ready static output

The included vercel.json selects no framework and publishes public. Its build command checks that the already-generated index, roadmap and validation page exist. This deliberately avoids assuming Go is installed on Vercel's remote build image. Before any future requested deployment, rebuild/check locally and include the resulting public directory with the project. The root's authoring source can remain private if publishing public alone.

Vercel output-directory documentation and build-image documentation were consulted. The local build and configuration are verified; remote deployment and project settings are not, because this hub has not been deployed.

Distribution

Serve public with any static server or open index.html locally for offline browsing. External reading links still need a network connection. If moving the site, retain all relative guide/download/assets paths. A ZIP of the complete academy workspace is supplied separately for review and further editing.
