Engineering Questions and Socratic Vision

Discuss these after the build. Use your own traces and code to defend a decision; there are no hidden answers.

  1. What exactly makes BFS shortest: the visited set, the queue or both?
  2. Which changes would be required if tunnels had unequal travel times?
  3. Why is a reconstructed path a useful certificate even when distance is the requested output?
  4. Can early stopping on discovery and on dequeue produce the same distance with different metadata completeness?
  5. Why is a map-backed neighbor order a reproducibility risk?
  6. How would a malformed parent chain reveal a search invariant failure?
  7. What does a single-ant shortest path fail to describe about multi-ant traffic?
