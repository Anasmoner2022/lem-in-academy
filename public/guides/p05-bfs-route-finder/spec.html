Full specification

  1. Implement Shortest(g,start,end) returning one path including both endpoints and its edge count. Validate indices and adjacency integrity.
  2. Use P04's sorted neighbors so equal-length route selection is deterministic. Mark discovery before enqueueing.
  3. For start==end return a one-vertex path and distance 0 in this general-purpose tool. The final colony grammar requires distinct terminals.
  4. For an unreachable target return a distinguishable error and no path. Ordinary cycles and disconnected extra rooms must not cause nontermination.
  5. Path length in edges equals len(path)-1; every consecutive pair must be adjacent. Bound reconstruction to V parent steps to detect a broken invariant.
  6. The CLI's JSON has Names, Links, Start and End. Print distance=D path=name,name,.... Coordinates do not affect route choice.
  7. Include queue tests and a justification of shortestness using distance layers. This tool does not allocate multiple ants or promise minimum completion turns for them.
