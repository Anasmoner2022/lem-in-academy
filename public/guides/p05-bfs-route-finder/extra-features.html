Level Up: extra features

Optional, ordered from small extensions to larger investigations. Pass the mandatory gates first.

  1. Return all distances from one source. Use them for later pruning without enumerating paths.
  2. Count shortest routes on a small graph. Decide how to handle integer overflow.
  3. Add a distance-to-end precomputation for time-layer pruning in P09.
  4. Benchmark line, star and grid graphs with the same vertex count.
  5. Compare bidirectional BFS on large sparse graphs. Preserve the route and tie-breaking contract before considering it an optimization.
