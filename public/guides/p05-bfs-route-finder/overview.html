Overview

Build a shortest-route inspector for an unweighted colony graph. It prints the shortest distance and one deterministic route, or a clear unreachable result. This is the correct tool for one ant's minimum travel time and a lower bound for many ants.

Reuse P04's canonical graph. You will build a queue with a head index, discover vertices once and reconstruct a path from parents. The artifact deliberately stops before claiming that one shortest route is an optimal multi-ant plan.

Prerequisite gate

Finish these builds first: P04 · Undirected Graph Inventory.

Planning estimate: 10 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
