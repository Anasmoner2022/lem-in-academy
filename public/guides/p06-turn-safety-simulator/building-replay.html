CHAPTER 8 OF 14

Check full replay completion

Give the final planner an independent behavioral witness.

Before writing code

  1. How is waiting represented?
  2. Does reaching end earlier allow an ant to move again?

Build in small passes

  1. Start all ant IDs at start and apply one Step per replay turn.
  2. Keep a turn counter and reject unfinished streams.
  3. Return a summary without importing or calling route planning code.

A grounded hint

The independent checker can share an immutable graph model, but should not reuse the planner's move-generation helper. Shared bugs would make a weak oracle.

Trace and self-check

For two ants on s-a-t, replay turns [1→a], [1→t,2→a], [2→t]. The summary is valid turns=3 arrived=2.

Exit gate

A valid pipeline, an incomplete stream and a midstream collision all have explicit expected outcomes.
