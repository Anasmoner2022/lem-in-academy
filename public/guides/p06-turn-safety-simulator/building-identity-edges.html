Validate identities and tunnel use

Reject illegal individual moves before changing occupancy.

Before writing code

  1. Can the source room in an output token be trusted?
  2. Why does reversing an edge not create a new tunnel?

Build in small passes

  1. Check ant IDs and derive sources from the old position slice.
  2. Track ants already moved and canonical tunnel keys.
  3. Reject unknown edges, no-op tokens and departure from end.

A grounded hint

For a direct s-t tunnel, two ants both moving to end still collide on the one physical tunnel. Unlimited terminal occupancy does not increase edge capacity.

Trace and self-check

Two ants at s both proposing t through s-t must fail even though end can hold both.

Exit gate

Separate tests reject duplicate ant, out-of-range ant, nonedge, repeated tunnel and movement from end.
