CHAPTER 7 OF 14

Apply a concurrent turn atomically

Permit pipelines while rejecting room collisions.

Before writing code

  1. How does a stationary ant differ from an ant departing this turn?
  2. Can validation depend on the order of tokens?

Build in small passes

  1. Validate the starting room occupancy.
  2. Construct departure and arrival counts, then validate final ordinary occupancy.
  3. Commit next positions only after all checks; retain original slices.

A grounded hint

A per-token sequential simulator can incorrectly reject a valid pipeline when tokens arrive in the opposite order. Batch counts make legality independent from presentation order.

Trace and self-check

Old positions [a,b], moves ant1→b and ant2→t are legal in either token order. Remove ant2's move: ant1's arrival is illegal.

Exit gate

Permutation tests preserve batch validity, and failed turns cannot change the input state.
