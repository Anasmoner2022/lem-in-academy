CHAPTER 4 OF 14

Full specification

  1. Implement Allocate(lengths,n) for positive path lengths and positive n. Return the minimum feasible integer deadline and counts per path, with sum counts=n.
  2. Preserve input path order for equal decisions. At the minimum deadline, allocate up to each path's deadline capacity in supplied order until all ants are assigned. Zero allocation is permitted.
  3. Use checked arithmetic and early capacity saturation at n; reject negative/zero lengths, nonpositive n and representational overflow.
  4. Build a schedule generator for explicitly supplied internally vertex-disjoint paths. Assign ant IDs by path order then launch order; advance existing ants before launching the next ant on each path. Check the result with P06.
  5. Reject overlapping ordinary rooms, duplicate path edges and malformed paths at the schedule boundary. Unlimited start/end do not authorize a duplicated direct tunnel.
  6. The CLI fixture uses lengths [2,4], n=4; print turns=4 counts=3,1.
  7. Submit a written counterexample: edges s-a, a-b, b-t, a-c, c-d, d-t, s-e, e-f, f-b. Reserving shortest s-a-b-t permanently blocks two disjoint routes s-a-c-d-t and s-e-f-b-t. For four ants, compare the shortest-only six-turn pipeline with the two-route five-turn pipeline. This demonstrates greedy failure; prove global optimality later with P11.
