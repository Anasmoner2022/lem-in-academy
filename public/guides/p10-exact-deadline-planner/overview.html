Overview

Build a planner library that takes an already validated graph and returns a minimum-turn schedule. It combines P05's distance lower bound, P09's deadline model and P08's integral max flow. It also extracts concrete ant trajectories and validates their movements with P06.

This is the last isolated algorithm build before integration. Do not add colony parsing here. The deliverable includes a schedule, a neighboring-deadline infeasibility witness and a correctness argument covering the search, reduction and extraction rather than only the flow engine.

Prerequisite gate

Finish these builds first: P09 · Capacity Through Time.

Planning estimate: 18 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
