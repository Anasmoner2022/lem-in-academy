CHAPTER 3 OF 14

Focused refresher

Let d be the BFS distance from start to end. No ant can arrive before d. Routing all n ants through one shortest simple path as a pipeline finishes by d+n-1, so that is a proven finite upper bound, including d=1.

Define F(T) as whether deadline T supports value n in the time-expanded network. F is monotone: extend a feasible schedule by keeping every finished ant at end. Binary search finds the first feasible T in [d,d+n-1]; a linear scan is also exact but uses more probes. A resource error is a third result, separate from true and false.

After the successful flow is found, decompose its positive original flow into n unit source-sink trajectories. The original network is a DAG ordered by time and gadget stage, so repeated unit extraction terminates. Ignore reverse residual arcs. Translate split/connector metadata into one room per boundary, normalize same-side gadget use to waiting and keep early arrivals at end.

Give trajectories ant IDs 1..n in deterministic extraction order. At each turn emit only IDs whose room changed, in increasing ID order. The planner assigns ants to time trajectories directly; P07's route-length allocation is a useful special case, not an extra heuristic step.
