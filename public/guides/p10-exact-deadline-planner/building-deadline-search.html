Search the first feasible deadline

Choose a correct optimization boundary with three-valued probe results.

Before writing code

  1. Why is d+n-1 feasible without solving max flow?
  2. What does a budget failure say about F(T)?

Build in small passes

  1. Compute d and checked bounds.
  2. Write down the binary-search invariant before implementing probes.
  3. Test that each probe uses fresh residual state and that errors propagate separately.

A grounded hint

A failed allocation cannot move your infeasible bound upward. It supplies no mathematical information about the deadline.

Trace and self-check

For s-a-t, n=3, bounds are [2,4]. T=3 carries two ants, so the minimum is 4. For two length-two branches and n=3, minimum is 3.

Exit gate

Boundary tests n=1, direct edge and single path all return the expected first feasible T.
