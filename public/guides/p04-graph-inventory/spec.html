Full specification

  1. Build an immutable Graph from unique names and canonical links. Revalidate indices and duplicate/self-edge invariants at this public boundary even if P03 normally guarantees them.
  2. Assign integer IDs by sorted names. Store every undirected tunnel exactly once in each endpoint's adjacency list; sort neighbors by the stable IDs.
  3. Report every connected component with names sorted inside it, and components ordered by their smallest name. Include isolated rooms.
  4. Report each vertex's degree and whether any ordinary cycle occurs. A triangle is valid and cyclic. A two-vertex single edge is acyclic.
  5. Do not use coordinates as distances, compare room names numerically or assume input order is a topological order.
  6. Use iterative traversals with O(V+E) work after canonical sorting. Copy mutable input slices if callers might retain them.
  7. The CLI accepts a small JSON graph fixture, prints adjacency lines a: b c, then components=N cyclic=true|false. No pathfinding or ant scheduling yet.
