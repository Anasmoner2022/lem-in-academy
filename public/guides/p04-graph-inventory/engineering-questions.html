Engineering Questions and Socratic Vision

Discuss these after the build. Use your own traces and code to defend a decision; there are no hidden answers.

  1. Why is a graph representation an API boundary rather than a detail hidden inside BFS?
  2. Which ordering guarantees should Graph provide to all later algorithms?
  3. What would change if the colony allowed parallel tunnels, and why does this assignment prohibit them?
  4. Why is disconnectedness a property to inspect before deciding it is a fatal route failure?
  5. When can a map be useful internally without making output nondeterministic?
  6. What is the tradeoff between revalidating public inputs and trusting the parser?
  7. How does a traversal invariant protect against exponential route enumeration?
