Verification and exit gates

The fixture has a triangle a-b-c-a and isolated z. Expected adjacency is a: b c; b: a c; c: a b; z: followed by no neighbors, then components=2 cyclic=true.

  • A single a-b edge: two degrees of 1, one component, no cycle.
  • A triangle: all degrees 2, one component, cycle true.
  • Triangle plus z: two components; cyclic remains true.
  • Duplicate reversed edge, self-edge or unknown name: error.
  • Permute all names and links repeatedly: exact inventory bytes remain equal.

Exit gate

Explain the two adjacency entries per tunnel, prove each vertex is visited at most once and show why coordinates play no role. Document sorting cost separately from linear traversal cost.

Submission evidence

Remove each acceptance test's explicit skip only when you begin that feature. Add tests for the failure boundaries described here, run go test ./... and go vet ./..., then show a reviewer a failing test produced by one deliberate bug and the repaired result. Submit the commands, input, expected result and actual result. A reviewer must inspect tests as well as pass counts.

Completion: the guide does not assess you automatically. Every required behavior and component gate must be demonstrated before a learner or instructor records readiness.
