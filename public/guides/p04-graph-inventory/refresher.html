Focused refresher

A graph has vertices (rooms) and edges (tunnels). An adjacency list stores only actual neighbors, using O(V+E) space for an undirected graph where each edge appears twice. A dense V×V table is unnecessary for sparse colonies.

Names belong at the boundary. Give each room a stable integer index; use that index in arrays for visited flags and parents. For reproducibility across input reorderings, assign IDs after sorting names bytewise, then sort each neighbor list.

type Graph struct {
    Names []string
    Adj [][]int
}
// A room's coordinate is display metadata, not an edge weight.

In an undirected DFS, the edge back to the parent is not a cycle by itself. Detect a visited neighbor that is not the parent. Use an explicit stack to avoid recursion depth depending on hostile file structure. Never enumerate all simple paths merely to find connected components.
