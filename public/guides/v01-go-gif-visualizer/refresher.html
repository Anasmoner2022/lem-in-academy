CHAPTER 3 OF 15

Focused refresher

Composition should keep parsing, simulation and rendering independent. P13 produces a validated history with room names, coordinates, tunnels and one position per ant at each boundary. P14 maps the fixed scene once and draws frames from those positions.

Interpolate only movement positions between validated boundaries. An ant traverses the drawn tunnel from its old room to its new one; waiting ants stay fixed. Collocated start/end ants can be rendered as a deterministic compact cluster or an aggregate marker, while the companion text preserves every ID.

Preflight the whole output before large frame allocation. A GIF is binary output, so do not mix diagnostic text into it. This academy writes binary GIF to a named file and leaves stdout available for a concise file summary. Invalid input must not leave an apparently successful final GIF.

// Published interface after students finish both executables:
// ./lem-in ant-farm.txt | ./visualizer
// Result: farm.gif, legend.txt, replay.txt in the current directory.
