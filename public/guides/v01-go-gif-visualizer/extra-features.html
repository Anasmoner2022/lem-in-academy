Level Up: extra features

Optional, ordered from small extensions to larger investigations. Pass the mandatory gates first.

  1. Add a Go-generated PNG contact sheet alongside the GIF for static review.
  2. Add numeric bitmap room IDs and ant IDs where space permits, retaining the text legend.
  3. Add configurable turn duration with a documented rounding policy for GIF delays.
  4. Render deterministic terminal clusters or count glyphs for large ant populations.
  5. Explore a Go-only isometric projection using the same raster primitives as a stretch project; retain 2D replay correctness and do not add an unrequested graphics dependency.
