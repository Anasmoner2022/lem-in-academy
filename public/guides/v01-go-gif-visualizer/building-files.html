CHAPTER 8 OF 15

Write bounded outputs safely

Avoid confusing failed or partial artifacts with successful visualization.

Before writing code

  1. When can output files be renamed to final paths?
  2. What happens if the second companion write fails?

Build in small passes

  1. Check destination collisions and require explicit overwrite policy.
  2. Encode and close owned temporary outputs, tracking every error.
  3. Finalize the output set and document/implement cleanup if a later rename fails.

A grounded hint

Closing a file can fail too. Do not declare success immediately after gif.EncodeAll returns if later file operations are still pending.

Trace and self-check

Inject a Writer that fails after a prefix. The final farm.gif path must not be presented as a completed artifact.

Exit gate

Output collision, encode failure, close failure and finalization failure have deliberate outcomes.
