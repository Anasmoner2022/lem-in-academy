Overview

Build visualizer, a Go-only consumer of valid lem-in stdout. It reads the echoed colony and ant movements from stdin, validates them, then writes an animated GIF showing ants travelling through the coordinate-defined colony. It also writes a legend and a text replay so the data remains reviewable without animation.

Reuse P13's immutable validated history and P14's mapper, raster primitives and GIF encoder. Core lem-in must already pass its own readiness gates. The bonus visualizes a schedule; it does not make a slow schedule optimal or repair an illegal one.

Feasible standard-library scope

GIF is the chosen rendering target because Go's standard library provides raster images and GIF encoding. An installed image viewer or browser can display the file without student JavaScript, a GUI toolkit or a third-party graphics package. A 3D visualizer is mentioned as an extra in the upstream audit, but is not required by this academy's optional 2D bonus.

Prerequisite gate

Finish these builds first: P14 · Go Raster and GIF Studio.

Planning estimate: 20 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
