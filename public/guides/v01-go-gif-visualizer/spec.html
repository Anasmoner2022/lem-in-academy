Full specification

  1. Compile the CLI as visualizer. With no arguments read stdin and write farm.gif, legend.txt and replay.txt. Optionally support -out path.gif, with companion files in the same selected directory.
  2. Decode the complete academy transcript using P13, independently validate legal movement and completion, and reject solver error output, malformed/truncated streams and Reader failures. A legal but suboptimal transcript can be visualized; label the output as a replay, never a proof of optimum.
  3. Draw every room and tunnel from the colony. Fit the supplied coordinates with P14's aspect-preserving transform, including negatives, zero spans and coincidences. Room identity is independent from coordinates.
  4. Use four interpolation frames per logical turn at the declared timing, plus initial/final holds. Draw ants moving along their actual tunnels; keep waiting/arrived ants represented. End on the actual all-end snapshot.
  5. Preserve names and every ant's identity in legend/replay text. If the image aggregates terminal ants or separates coincident markers for visibility, document that display policy and retain exact positions in the companion text.
  6. Keep all student code standard-library-only, with no browser script, third-party fonts, graphics library or external encoder. GIF, PNG and text files are generated by Go.
  7. Apply P13's input bounds and P14's frame, dimension and total-pixel bounds; check arithmetic before allocation. Return a distinct resource error without dropping turns, shrinking the requested dimensions silently or presenting a partial final GIF as success.
  8. Use temporary files in the destination directory while writing. Finalize only after encoding and closing succeed; clean up owned temporary files on failure. Do not overwrite an existing output set without an explicit documented -overwrite flag. Multi-file rename is not fully atomic: document cleanup and rollback behavior.
  9. On success stdout names the three files; diagnostics go to stderr and failures return nonzero. No auto-opening viewer is required. Include decode-back metadata tests, logical-boundary pixel checks, pipeline tests and actual visual inspection.
