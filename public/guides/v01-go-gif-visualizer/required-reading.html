Required reading

Mandatory before building

  • Official lem-in subject — Bonus and its pipe example. Preserve the producer-consumer interface and use coordinates for visualization.
  • image/gif package — GIF; EncodeAll; DecodeAll. Encode bounded animation and verify it independently.
  • io package — Reader; Writer; Pipe. Keep stdin consumption and output errors explicit.
  • os package — CreateTemp; Rename; Remove. Manage output files safely when generation or writing fails.

Recommended while building

  • flag package — FlagSet and error handling. Offer a small optional -out flag while preserving the no-argument pipeline.
  • Official audit — General visualizer questions. Distinguish the suggested visual bonus from mandatory solver behavior.

Reuse and readiness

Finish these builds first: P14 · Go Raster and GIF Studio.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
