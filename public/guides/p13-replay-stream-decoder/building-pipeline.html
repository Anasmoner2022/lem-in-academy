CHAPTER 8 OF 14

Test producer and consumer failures

Make pipeline behavior deliberate across platform boundaries.

Before writing code

  1. Who closes a pipe on producer failure?
  2. How do you avoid blocking while waiting for both processes?

Build in small passes

  1. Use bytes.Reader for deterministic unit fixtures.
  2. Add an io.Pipe test that sends a valid prefix then an error.
  3. For process integration, start the producer, connect output to the decoder and wait/check both outcomes.

A grounded hint

Use os/exec argument slices rather than a shell command string. This avoids quoting differences and preserves Unicode bytes in the Go integration test.

Trace and self-check

Terminate the producer after the middle turn. The decoder must reject incomplete replay and the harness must finish without leaking a waiting goroutine.

Exit gate

Valid stream, producer failure, decoder failure and EOF truncation all terminate under a test timeout.
