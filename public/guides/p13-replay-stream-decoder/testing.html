Verification and exit gates

The fixture's snapshots must be:

turn=0 positions=s,s
turn=1 positions=a,s
turn=2 positions=t,a
turn=3 positions=t,t
  • Delete the final movement: incomplete replay error.
  • Append a movement after completion: rejected.
  • Use L1-west-hall for an existing hyphenated room: decode the full destination.
  • Keep one ant stationary during a turn: its position is retained.
  • Mutate one returned snapshot in a test and verify others do not share storage.
  • Send a Reader error after a valid prefix: no accepted replay.

Exit gate

The decoder exposes only fully validated histories and does not import planner logic. Demonstrate a portable Go pipeline test and describe the shell byte-handling assumption separately.

Submission evidence

Remove each acceptance test's explicit skip only when you begin that feature. Add tests for the failure boundaries described here, run go test ./... and go vet ./..., then show a reviewer a failing test produced by one deliberate bug and the repaired result. Submit the commands, input, expected result and actual result. A reviewer must inspect tests as well as pass counts.

Completion: the guide does not assess you automatically. Every required behavior and component gate must be demonstrated before a learner or instructor records readiness.
