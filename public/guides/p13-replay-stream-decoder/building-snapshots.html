CHAPTER 7 OF 14

Build immutable validated snapshots

Give rendering a trustworthy room-state timeline.

Before writing code

  1. What mutation would make every stored frame equal to the final frame?
  2. Where are waiting ants represented?

Build in small passes

  1. Create initial positions at start.
  2. Validate each batch using independent replay rules.
  3. Append copied next-position arrays with increasing turn numbers.

A grounded hint

Retain n positions even when several ants share start/end. A set of occupied rooms loses ant multiplicity and identity.

Trace and self-check

For two ants on s-a-t, snapshots are [s,s], [a,s], [t,a], [t,t]. Mutating a test copy of the last slice must not alter the first.

Exit gate

History is immutable, complete and consistent with the original token stream.
