Focused refresher

A producer's stdout becomes the consumer's stdin. EOF only means the stream ended; it does not prove all ants arrived. A solver invalid-data line is not a valid replay. The decoder must reject it rather than create an empty animation.

A snapshot is the full position array at one boundary, including turn 0. Copy each slice when storing history. Appending the same mutable slice repeatedly produces frames that all show the final state.

type Snapshot struct {
    Turn int
    Positions []int // caller-visible immutable copy
}

Consume the declared echo, one blank separator and movement batches. Support hyphenated destination names by splitting the ant prefix only once. Validate each turn before exposing its next snapshot. Rendering may interpolate between snapshots, but must not invent different logical motion.
