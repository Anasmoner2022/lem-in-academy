Required reading

Mandatory before building

  • bufio package — Scanner; Buffer; Err. Read a bounded transcript without losing scanner failures.
  • io package — Reader; LimitReader; Pipe. Define ownership and bounded stream consumption.
  • os/exec package — Cmd.StdoutPipe; Start; Wait. Test producer-consumer behavior in Go without shell-specific text transformations.
  • Official lem-in bonus — Bonus: visualizer consumes lem-in output. Keep the bonus interface compatible with the published pipeline.

Recommended while building

  • Go bytes package — Buffer; NewReader. Test replay decoding without external processes.

Reuse and readiness

Finish these builds first: L01 · Lem-in: Minimum-Turn Colony.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
