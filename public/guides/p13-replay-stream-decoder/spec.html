Full specification

  1. Implement Decode(r,maxBytes) for the academy transcript grammar. Apply a 16 MiB stream cap, line cap and bounded ant/turn counts, and at most 4000000 stored ant-time position cells. Check history growth before copying a next snapshot. Unknown commands remain in the echoed colony but have no movement meaning.
  2. Return colony room names/coordinates, tunnels, start/end, and immutable snapshots for boundaries 0..T. Validate all tokens and turns independently, require every ant at end and forbid extra movement after completion.
  3. Reject malformed echo, missing/extra separator, truncated replay, invalid-data solver output, bad ant IDs, unknown destinations, room/tunnel violations and Reader failures. Return no accepted replay on error.
  4. Snapshot 0 contains every ant at start. Waiting ants retain positions. Arrived ants stay at end. Store stable room indices from the canonical graph and preserve a room-name legend.
  5. The CLI accepts zero arguments for stdin or one transcript path for fixtures. Print a text table with turn=K positions=name,... in ant ID order.
  6. Include an integration test using Go os/exec or io.Pipe that handles producer errors and closes pipes. Do not equate pipeline EOF with producer success.
  7. PowerShell versions differ in native pipeline byte handling. For exact UTF-8 cross-process tests, use a small Go os/exec harness connecting streams directly; the simple native pipe remains the published usage example. No student JavaScript or external package is required.
