Decode stream framing

Separate accepted colony data from movement lines safely.

Before writing code

  1. What makes the first empty line meaningful?
  2. How does solver error output differ from an empty colony?

Build in small passes

  1. Read within the total/line budgets and propagate Reader errors.
  2. Find the exact echo separator and parse the colony.
  3. Reject missing movement data and obvious solver-error streams before producing snapshots.

A grounded hint

The colony grammar rejects blank data lines, so the first empty normalized line is an unambiguous separator. A second empty line is an invalid empty movement turn.

Trace and self-check

Feed ERROR: invalid data format alone. The decoder must return an error rather than a replay with zero rooms.

Exit gate

Missing separator, extra blank line, truncated input and injected read failure are independently tested.
