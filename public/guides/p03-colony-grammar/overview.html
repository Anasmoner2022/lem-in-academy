Overview

Build a colony inspection CLI that accepts a bounded text document and returns a validated colony model. It stops before graph search. The useful artifact is a parser whose errors identify the physical line and whose accepted document can later be echoed without reconstruction.

Reuse P02's reader and normalized Echo contract. Replace P01's notebook grammar with the actual lem-in language. Keep parsing and graph traversal separate: an otherwise valid disconnected colony can parse successfully, then fail reachability in P05.

Prerequisite gate

Finish these builds first: P02 · Bounded File Reader.

Planning estimate: 14 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
