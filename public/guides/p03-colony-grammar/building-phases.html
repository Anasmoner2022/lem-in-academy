CHAPTER 6 OF 14

Build the phase transitions

Recognize each line without guessing from token counts alone.

Before writing code

  1. When does the room dictionary become immutable?
  2. Can an unknown command accidentally consume a pending terminal marker?

Build in small passes

  1. Write a transition table for every line class in each phase.
  2. Classify trimmed comments and commands first, retaining physical line numbers.
  3. Advance to links only after a uniquely resolved first tunnel; reject rooms thereafter.

A grounded hint

An ignored ##color between ##start and a room must not make the marker disappear. A pending marker reaching a tunnel is an error.

Trace and self-check

Trace count, ##start, # note, ##unknown, s 0 0. The marker must bind to s. Now replace the room by ##end: reject at that line.

Exit gate

Your table and tests cover every phase crossed with count, room, link, comment, marker, unknown command and blank line.
