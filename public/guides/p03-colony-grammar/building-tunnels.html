CHAPTER 8 OF 14

Resolve undirected tunnels and failures

Parse links without narrowing the upstream name language.

Before writing code

  1. What should a-b-c mean if a, b-c, a-b and c all exist?
  2. Why are a-b and b-a the same physical resource?

Build in small passes

  1. Inspect candidate hyphen splits using known names and require exactly one match.
  2. Reject u==v and store an ordered endpoint pair for duplicate detection.
  3. Return a line-aware error and no usable colony for every invalid branch.

A grounded hint

Keep integer room IDs in canonical pairs. Lexically splitting an endpoint name into fragments is not an alternative grammar.

Trace and self-check

With rooms a and b-c only, a-b-c resolves to a ↔ b-c. With all four names above, the same line is ambiguous and must fail.

Exit gate

Reversed duplicate, self-link, unknown endpoint and ambiguous hyphen cases are tested separately.
