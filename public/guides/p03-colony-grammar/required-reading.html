Required reading

Mandatory before building

  • Official lem-in subject — Objectives; Instructions; Usage examples. Separate actual colony rules from parser policies chosen by the academy.
  • strings package — Fields; HasPrefix; Cut; Index. Tokenize rooms while retaining original physical lines.
  • strconv package — ParseInt; Atoi. Reject numeric overflow instead of accepting zero or truncated values.

Recommended while building

  • Unicode package — IsSpace; IsControl. Apply name rules consistently to valid UTF-8 text.
  • Go testing — Subtests and Fuzzing. Organize grammar cases and later fuzz the parser.

Reuse and readiness

Finish these builds first: P02 · Bounded File Reader.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
