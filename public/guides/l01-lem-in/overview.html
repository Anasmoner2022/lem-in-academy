Overview

Build the actual lem-in executable. It accepts one colony file, finds a legal schedule delivering every ant in the fewest turns, echoes the accepted input and prints one movement line per turn. This is the integration assignment, not a new opportunity to replace exact planning with a greedy shortcut.

Reuse the reader from P02, grammar from P03, graph from P04, BFS from P05, independent checker from P06, residual engine from P08, time model from P09, exact planner from P10 and evidence tools from P11/P12. P01 supplies Go foundations; P07 explains allocation and greedy failure. Port these into one module with clear package boundaries and no third-party dependencies.

Deliverable

Source, meaningful tests, adversarial fixtures, a README with the published academy policies and algorithm proof, repeatable verification commands, a complexity/resource note and measured audit compatibility results. The supplied starter deliberately contains no solver.

Prerequisite gate

Finish these builds first: P12 · Deterministic and Bounded Release Lab.

Planning estimate: 40 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
