CHAPTER 9 OF 17

Extract ants and validate every turn

Convert an anonymous feasible flow into an observable legal schedule.

Before writing code

  1. Which original arcs retain physical room-time meaning?
  2. How are waits kept out of the movement text?

Build in small passes

  1. Peel n unit paths using stable original flow order.
  2. Decode room trajectories and normalize same-side gadget traversals to waits.
  3. Pass every turn through an independent validator and require all ants at end.

A grounded hint

Keep the validator independent from move generation. A helper used by both to decide edge legality can make the same mistake twice.

Trace and self-check

For three ants on s-a-t, one valid optimal transcript has launches on turns 1,2,3 and final arrival on turn 4. Different extraction IDs are allowed only if deterministic and all constraints still hold.

Exit gate

Every generated schedule passes the black-box movement checker and repeated output comparison.
