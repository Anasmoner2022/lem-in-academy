Focused refresher

The pipeline is read → parse → canonical graph → reachability → exact deadline search → trajectory extraction → independent replay → format → write. Each boundary has a typed result or error. Do not echo anything before the complete plan has passed validation.

For a graph with shortest distance d and n ants, search deadlines in [d,d+n-1]. Each deadline uses integral max flow on a time-expanded network with room splits, holdovers and one shared tunnel bottleneck per turn. Successful flow becomes n trajectories; omitted movements are waits. A BFS lower bound or exhausted T-1 cut supports the minimum-turn claim.

The upstream second usage example demonstrates pipelining into a room vacated that turn. The academy interprets turns as batches with departures before arrivals, validates occupancy at each boundary and sorts tokens by ant ID. Ant identity never grants extra room or tunnel capacity.
