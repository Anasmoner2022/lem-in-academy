Full specification

  1. Implement checked network-size estimation from V,E,T. Invalid negative parameters and arithmetic overflow are errors. Return int64 counts before any potentially unsafe conversion.
  2. Academy default limits: 1 MiB input, 4096-byte physical lines, 10000 ants, 10000 rooms, 50000 tunnels, 200000 expanded vertices, 1000000 stored residual arcs, 4000000 stored ant-time position cells, 16 MiB formatted output and a 240-second planning deadline. These are academy resource policies, not upstream graph-size guarantees.
  3. Check budgets before allocation and periodically during BFS augmentation, deadline probes and extraction. On exhaustion return a distinct error and no claimed optimal plan. Never substitute a greedy result. Allow a documented instructor-configured budget without weakening exactness.
  4. Format a complete accepted transcript only after parsing, planning and independent movement validation. Keep diagnostics off successful stdout. Canonical token order is ascending ant ID, single ASCII spaces, LF lines and no trailing spaces.
  5. For final L01: success exit 0; malformed/no-route input prints one ERROR: invalid data format line with optional suffix to stdout, exit 1; usage/I/O errors go to stderr, exit 2; resource exhaustion goes to stderr as ERROR: resource limit exceeded, exit 3. Writer failure is an I/O error; never print a second error into an already partial success transcript.
  6. The prep CLI prints vertices=36 original_arcs=51 residual_arcs=102 for V=3,E=2,T=3. Keep the final process adapter as a separate future component.
  7. Release evidence includes gofmt, tests, vet, a standard-library dependency inspection, 20 repeated-output comparisons, boundary resource tests and recorded performance hardware/toolchain. Upstream timing gates: example06 with 100 ants below 90 seconds, example07 with 1000 below 150 seconds; do not claim those measurements before running a finished solver.
