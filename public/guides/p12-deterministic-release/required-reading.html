Required reading

Mandatory before building

  • Go command documentation — Build; Test; Vet; List. Make standard Go checks reproducible.
  • context package — WithTimeout; Context.Err. Propagate a work deadline through expensive planning loops.
  • Official good practices — Code; Go; Time Limitation. Review structure, formatting and bounded execution expectations.

Recommended while building

  • math package constants — Integer limit constants. Reason about bounded arithmetic rather than trusting overflow behavior.
  • Official lem-in audit — example06 and example07 timing checks. Treat the published timing examples as separate performance gates.

Reuse and readiness

Finish these builds first: P11 · Adversarial Validator and Tiny Oracle.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
