CHAPTER 6 OF 14

Preflight bounded work

Reject unsafe sizes before allocation without misclassifying feasibility.

Before writing code

  1. Which arithmetic expression can overflow first?
  2. Does a model-size refusal mean the colony has no route?

Build in small passes

  1. Implement checked count arithmetic and compare each count with policy.
  2. Bound trajectory cells n(T+1), output token estimates and actual formatting growth before allocating extraction history.
  3. Add cancellation checks at bounded intervals inside all expensive loops.

A grounded hint

Doubling original arcs for residual pairs matters. A policy based only on forward arcs underestimates the actual graph storage.

Trace and self-check

For V=3,E=2,T=3, calculate 24+12=36 vertices, original arcs 21+30=51 and residual arcs 102. Derive each term from room layers and tunnel gadgets.

Exit gate

Arithmetic boundary tests and a forced low-budget run return resource errors before allocation.
