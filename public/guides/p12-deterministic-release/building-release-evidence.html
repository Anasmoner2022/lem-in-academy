CHAPTER 8 OF 14

Reproduce a release review

Make correctness and performance claims reviewable.

Before writing code

  1. What is measured by scaffold compilation versus solution acceptance tests?
  2. Which timing gate is machine-dependent?

Build in small passes

  1. Run standard Go build/test/vet checks and inspect imports.
  2. Compare 20 outputs from the same fixed input byte-for-byte.
  3. Run the P11 campaign and published audit examples on the completed implementation, logging versions and hardware.

A grounded hint

A test suite with skipped TODO acceptance cases proves the starter is well formed, not that the student's program works. Count skipped tests in your report.

Trace and self-check

A report must say pending if example07 has not been executed. An inferred complexity bound is not a measured 150-second result.

Exit gate

Every claim in the release report points to a command, an input, an actual result and any limits.
