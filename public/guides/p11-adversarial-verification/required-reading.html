Required reading

Mandatory before building

  • Go testing — Fuzzing; Subtests; Benchmarks. Create reproducible generative tests and shrink failures.
  • Go fuzzing tutorial — Add a fuzz test; Fix the bug; Explore additional resources. Learn seed corpus and failure reproduction practices.
  • Official lem-in examples — example00 through example07; badexample00 and badexample01. Use upstream examples as compatibility cases, not an exhaustive correctness proof.
  • Official lem-in audit — Functional checks and timing examples. Record expected turn ceilings and performance cases honestly.

Recommended while building

  • math/rand package — New; NewSource. Generate deterministic local test sequences from a recorded seed.

Reuse and readiness

Finish these builds first: P10 · Exact Deadline Planner.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
