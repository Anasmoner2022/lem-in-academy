Full specification

  1. Implement a bounded transcript checker requiring the full echo and exactly one blank separator. Reparse the echoed colony under the published policy, then validate movement spelling, ant IDs, known destination names, no duplicate IDs per line and ID-ascending canonical output.
  2. Apply P06 batch rules to every movement line. Reject empty movement lines, extra diagnostics, unfinished ants, movement after completion and invalid EOF. Require the accepted echo to match the submitted input after P02 normalization when the original file is supplied.
  3. Implement Oracle with exhaustive occupancy-state BFS, not P08/P09 calls. Return the first all-end depth or no-route only after complete bounded exhaustion. A budget breach is a distinct error.
  4. Enumerate wait/move combinations from each old state, enforce undirected edge use and boundary room occupancy independently, then canonicalize indistinguishable ants. End ants only wait. Preserve reproducible parent metadata for a discrepancy witness.
  5. Cross-check planner turns against oracle turns over every simple labelled graph with V=2..5, fixed terminals 0 and V-1 and n=1..3, within the chosen budgets. Include disconnected graphs. Add fixed-seed random V=6 cases and preserve exact seeds if you run them.
  6. Include direct edge, single corridor, diamond, bottleneck, cycles, disconnected extras, no route, hyphenated names and P07's greedy trap. Mutate accepted transcripts to target every checker rejection rule.
  7. The CLI fixture uses s-a-t with three ants. Print oracle_turns=4. Report counts of cases run, mismatches, skipped budget cases and actual command/toolchain; a green scaffold test does not mean this campaign ran.
