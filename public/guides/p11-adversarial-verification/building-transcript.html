CHAPTER 6 OF 14

Parse and replay an untrusted transcript

Check observable behavior without trusting planner internals.

Before writing code

  1. Where is the colony/movement boundary?
  2. How do you parse a destination containing a hyphen?

Build in small passes

  1. Parse the bounded echo and exact separator.
  2. Validate token syntax and canonical ID order, deriving source rooms from old state.
  3. Run independent replay and require complete absorption at end.

A grounded hint

L12-west-hall means ant 12 to room west-hall. Splitting the entire token on every hyphen would corrupt a valid destination.

Trace and self-check

Mutate a valid token to L0-a, duplicate L1 in one line, and append a diagnostic line. Each must be rejected for a distinct reason.

Exit gate

The checker rejects all targeted token and replay mutations while accepting the original valid transcript.
