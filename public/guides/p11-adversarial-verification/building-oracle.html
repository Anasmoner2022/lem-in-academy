CHAPTER 7 OF 14

Search tiny occupancy states exhaustively

Prove small-instance optimality by a different state space.

Before writing code

  1. Why can ant identities be omitted when only the minimum completion time is asked?
  2. What must be enumerated to make the oracle exact?

Build in small passes

  1. Canonicalize a valid occupancy multiset and use it as a visited key.
  2. Enumerate all wait/neighbor choices for each ant and independently check each full batch.
  3. BFS the resulting state graph until all-end or complete exhaustion, enforcing explicit budgets.

A grounded hint

Two equal start positions describe two ants, not one. Deduplicating room IDs instead of sorting the full multiset would lose ants.

Trace and self-check

For two ants on s-a-t, list states at depths 0..3. The first all-end state is at depth 3.

Exit gate

The oracle gets direct-edge, corridor and two-branch minima by exhaustive search without using flow code.
