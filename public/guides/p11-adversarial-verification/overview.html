Overview

Build two review tools: a black-box checker for a complete lem-in transcript and a tiny exhaustive optimality oracle. The checker proves legality and completion; the oracle explores joint occupancy states instead of using flow, providing independent evidence about minimum turns on small colonies.

Reuse P03's declared grammar, P06's move invariants and P10's planner as a system under test. Keep the oracle independent from the time-expanded model and residual engine. The delivered artifact includes reproducible random seeds, named adversarial fixtures, mutation tests and a discrepancy report.

Prerequisite gate

Finish these builds first: P10 · Exact Deadline Planner.

Planning estimate: 14 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
