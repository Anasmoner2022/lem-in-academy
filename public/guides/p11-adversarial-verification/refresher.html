Focused refresher

A transcript contains a normalized accepted-input echo, one empty separator line, then movement lines. Tokens encode only ant ID and destination, so derive each source from replay state. Split after the first hyphen following the ant number; the destination itself may contain hyphens.

A small oracle can search the finite set of occupancy states. A state is a sorted multiset of room IDs occupied by n indistinguishable ants; repeated IDs are legal only at start/end. For each state, enumerate each ant's wait or adjacent move choices, reject shared tunnel use and invalid next occupancy, sort the next multiset and perform BFS over states. Keep end absorbing. This is a different algorithm from flow.

State BFS depth is the number of turns. The first all-end state proves minimum turns because every legal next batch was considered. Keep the tiny limit explicit: V≤6 and n≤3 for the academy oracle, plus state/transition budgets. Exceeding a budget means unknown, not no route.
