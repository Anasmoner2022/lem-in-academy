Overview

Build a model compiler: given a colony graph, an ant count and a deadline T, emit a directed capacity network for P08. The network answers whether all ants can reach end by T. The deliverable includes metadata linking network arcs back to rooms and turns, a printed small-network inventory and a written correspondence argument.

Reuse P06's batch semantics and P08's integral flow engine. The new concepts are vertex splitting, time layers, holdovers and a shared tunnel gadget. This modelling project is separate from searching for the best deadline, which comes in P10.

Prerequisite gate

Finish these builds first: P08 · Residual Flow Workbench.

Planning estimate: 16 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
