CHAPTER 6 OF 14

Build the typed model

Make room records and their invariants visible in types and tests.

Before writing code

  1. Which fields are required even when their numeric zero value is valid?
  2. What does passing a slice copy, and what does it share?

Build in small passes

  1. Define two rooms with negative and zero coordinates in a table-driven test.
  2. Implement name and duplicate validation without relying on map iteration order.
  3. Return an error before producing output when any record is invalid.

A grounded hint

Track names in a local map, but preserve input order for identifying the first invalid record. A coordinate of zero must never be treated as missing.

Trace and self-check

Trace [atrium, exit, atrium]. The third record must fail even if its coordinates differ. Trace an empty slice: no error.

Exit gate

Tests cover a valid record, an invalid name, a duplicate, zero coordinates and empty input.
