Level Up: extra features

Optional, ordered from small extensions to larger investigations. Pass the mandatory gates first.

  1. Add a count-only mode. Keep its output contract separate from the inventory mode so tests remain precise.
  2. Support an optional name prefix filter. Decide whether filtering happens before or after validation and justify it.
  3. Include line or record context in errors. Preserve the original underlying error where wrapping is useful.
  4. Add a benchmark comparing sorting a copied slice with sorting an index slice. Measure before choosing.
  5. Document a migration from value fields to optional coordinate pointers. Explore how missing and zero would differ without implementing a new storage system.
