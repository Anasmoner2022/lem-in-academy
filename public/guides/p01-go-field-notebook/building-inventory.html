CHAPTER 7 OF 14

Build stable inventory output

Separate a valid model from its presentation.

Before writing code

  1. Would sorting the original slice surprise a caller?
  2. What should appear after the final record?

Build in small passes

  1. Create an output ordering without changing the input slice.
  2. Format signed integer coordinates consistently.
  3. Compare exact bytes in a golden test and compare the input before and after the call.

A grounded hint

A copy of a slice of Room values is enough because Room contains only strings and ints. Later nested slices need a different copying argument.

Trace and self-check

For input z 1 0 followed by a -2 5, predict a -2 5 then z 1 0, each ending in LF. Confirm the original first record is still z.

Exit gate

Ten runs produce identical bytes and a mutation check passes.
