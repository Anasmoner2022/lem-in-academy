Full specification

Notebook contract

  1. Accept exactly one input path. Read a JSON array of objects with Name, X, Y. Use only the standard library. Reject malformed JSON, trailing JSON data, missing names and duplicate names.
  2. Names are nonempty ASCII letters, digits or underscore; the first character cannot be L or #. For this notebook, x/y are Go ints. Negative and coincident coordinates are valid.
  3. Print accepted rooms in ascending bytewise name order as name x y, one newline per record. Do not mutate the caller's slice when obtaining sorted output.
  4. Empty arrays are valid and print nothing. Validation errors produce no inventory and return a useful error identifying the offending record.
  5. Implement ValidateRooms and Inventory as pure functions. The supplied main only delegates to Run; implement JSON decoding and output wiring yourself.

Out of scope

No tunnels, terminal commands, pathfinding, persistent database or goroutines. This small input grammar is intentionally different from the later colony parser.
