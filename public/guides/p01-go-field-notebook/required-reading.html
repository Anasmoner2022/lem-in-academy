Required reading

Mandatory before building

  • Tutorial: Create a Go module — Create a module; Call your code from another module. Understand go.mod, package names and local executable builds.
  • A Tour of Go — Basics: Packages, variables and functions; Flow control; More types: structs, slices and maps. Translate your existing programming knowledge into the Go constructs used here.
  • Return and handle an error — Errors as return values. Build explicit failure paths without panic for user input.
  • Add a test — Test functions and go test. Learn the test file and assertion conventions.

Recommended while building

  • Effective Go — Names; Formatting; Slices; Maps. Review idiomatic naming and avoid assuming map iteration is stable.

Reuse and readiness

Basic programming, terminal use, files and Git; no Go assumed.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
