CHAPTER 1 OF 14

Overview

Build a room notebook that accepts small JSON records, validates names and coordinates, and prints a stable inventory. This is your first Go program, so the deliverable includes a working module, an error contract, tests and a short explanation of value versus reference behavior.

Your existing programming experience helps with loops and conditions. Go adds explicit types, multiple return values, zero values and a compiler that rejects unused imports. Practice these on a small artifact before colony grammar makes failures harder to isolate.

Deliverable

A CLI reading one JSON array from a file argument and printing one room per line in name order, plus table-driven tests for the pure validation function. This is a notebook format, not the lem-in format. Later projects reuse the Room record and error-handling pattern.

Prerequisite gate

Basic programming, terminal use, files and Git; no Go assumed.

Planning estimate: 8 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
