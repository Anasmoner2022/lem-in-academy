Engineering Questions and Socratic Vision

Discuss these after the build. Use your own traces and code to defend a decision; there are no hidden answers.

  1. Which invariants belong in a type and which still need runtime validation in this notebook?
  2. How would pointer fields change your argument that copying the room slice prevents mutation?
  3. Why can a zero-valued coordinate be valid while a zero-length name cannot?
  4. Which validation error should win when several records are wrong, and why?
  5. What does deterministic output buy a reviewer comparing two program runs?
  6. How would you separate a filesystem error from a record validation error without losing context?
  7. What evidence shows that a passing test exercises behavior instead of merely reproducing implementation steps?
