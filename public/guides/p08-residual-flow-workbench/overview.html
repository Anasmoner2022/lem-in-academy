Overview

Build a directed network workbench that sends integral flow from a source to a sink. It reports the achieved value, per-original-edge flow and a reachable-side cut after exhaustion. Reverse arcs let the algorithm cancel part of an earlier decision, addressing the greedy failure exposed in P07.

Reuse the BFS worklist pattern from P05, but search only arcs with positive residual capacity. No rooms or time layers are hidden inside this engine. Keeping the engine generic lets P09 test the modelling reduction separately.

Prerequisite gate

Finish these builds first: P07 · Traffic and Ant Allocation Lab.

Planning estimate: 14 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
