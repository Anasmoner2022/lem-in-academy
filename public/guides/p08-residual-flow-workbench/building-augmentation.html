CHAPTER 7 OF 14

Find and apply augmenting paths

Use BFS without freezing previous routing choices.

Before writing code

  1. Why do parent records need an arc index?
  2. What bounds the amount added on one path?

Build in small passes

  1. Run residual BFS and retain an arc chain.
  2. Calculate the bottleneck including the remaining target.
  3. Apply paired updates and check capacity/conservation invariants after each augmentation during development.

A grounded hint

Use the directed network s→a, s→b, a→b, a→t, b→t with unit capacities. Manually seed flow on s-a-b-t; then a residual path s-b-a-t must cancel a→b and increase total flow to two.

Trace and self-check

After the reroute, original flow on a→b is zero, while s→a→t and s→b→t each carry one. The reverse arc was bookkeeping, not a final extra route.

Exit gate

A forced reroute test fails with reverse arcs disabled and passes with correct paired updates.
