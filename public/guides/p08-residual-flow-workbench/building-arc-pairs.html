CHAPTER 6 OF 14

Build residual arc pairs

Make cancellation explicit and testable.

Before writing code

  1. What does a reverse arc mean before any flow is sent?
  2. How will original antiparallel arcs remain distinct?

Build in small passes

  1. Allocate stable arc handles and reverse indices.
  2. Retain original capacities independently from current residual capacity.
  3. Test pair symmetry and update a single arc manually in a small unit test.

A grounded hint

For a capacity-one arc, sending one unit changes residuals from (1,0) to (0,1). Sending it back must restore (1,0), not create extra capacity.

Trace and self-check

Add original a→b and original b→a. Draw four residual arc records and their pair links.

Exit gate

Reverse indices point back to their originating arc, including with antiparallel original arcs.
