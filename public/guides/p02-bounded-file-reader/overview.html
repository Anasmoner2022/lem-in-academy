Overview

Build a line inspection tool for colony files. Its job is to read a bounded file, normalize line endings under a stated policy and report numbered lines without interpreting rooms or links. You will isolate transport failures from semantic failures before introducing a grammar.

Reuse P01's module workflow, returned errors and output tests. The new material is io.Reader, file ownership, EOF, Scanner limits and a transactional output boundary. Deliver the reader package functions, a CLI, boundary fixtures and tests with injected readers and writers.

Prerequisite gate

Finish these builds first: P01 · Go Field Notebook.

Planning estimate: 10 focused hours before review. Add 25–50% if Go or the mathematical model is new. Learner completion remains unassessed.
