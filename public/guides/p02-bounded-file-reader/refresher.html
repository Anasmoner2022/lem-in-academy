Focused refresher

io.Reader.Read may return bytes and an error together. EOF is normal only after all returned bytes have been consumed. Small reads do not necessarily mean EOF. Use standard helpers instead of assuming one Read fills a buffer.

To distinguish exactly-at-limit from over-limit, request at most limit+1 bytes and reject if that extra byte exists. A bounded reader returning EOF at the limit cannot alone prove that the source ended there. Scanner token limits are a second, independent limit.

f, err := os.Open(path)
if err != nil { return err }
defer f.Close() // ownership begins after successful Open
// Pass f to your reader boundary; do not parse room names here.

Use injected readers for failure tests. A strings.Reader cannot simulate every filesystem failure, so a tiny custom Reader can return bytes followed by a sentinel error. Do not use goroutines merely because I/O is involved.
