Wiring and running

The supplied main function delegates to Run. Implement the project boundary and connect the components from the guided chapters. Do not print debugging data into a machine-readable stream.

Run inside the extracted module

go test ./...
go vet ./...
go build -o line-reader .
# Windows executable name: go build -o line-reader.exe .
go run . testdata/lines.txt

Troubleshooting

  • ErrTODO is expected until you implement the contract. Never mark that result as a completed project.
  • If Go cannot find a module, change into the folder containing this project's go.mod. No external module downloads are needed.
  • On Windows, run the built executable with .\; on Unix use ./. Go commands themselves are the same.
  • If output differs, compare structure and errors before changing a golden file. Stable ordering must come from the program, not repeated retries.
