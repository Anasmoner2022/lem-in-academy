Full specification

Reader contract

  1. Implement ReadDocument(r, limits). Limits are positive; the academy default is 1 MiB total input and 4096 bytes per physical line, excluding CRLF/LF terminators.
  2. Accept LF and CRLF. Normalize CRLF to LF, reject any bare CR and NUL. Preserve every other byte, including comments, leading/trailing spaces and non-ASCII bytes; the next project decides grammar validity.
  3. A final newline is optional. Store logical lines without terminators and an echo string containing the normalized lines joined by LF with exactly one final LF. An empty file returns an empty document; P03 rejects it as a colony.
  4. Do not invent an empty final line from a final newline. Preserve an actual interior blank line for the parser to reject later. Both byte and line limits apply before further allocation grows beyond the bound.
  5. The CLI requires one file path and prints numbered lines in the form 1: text. Reader, size, usage and writer failures return errors; no partial report is printed before the complete read succeeds.
  6. Do not close a caller-owned Reader. Run owns the file it opens. Check Scanner.Err if using Scanner; configure its buffer from the line policy.

No colony validation or pathfinding belongs in this tool. The normalized Echo is a deliberate academy policy; upstream only asks for accepted content to be displayed.
