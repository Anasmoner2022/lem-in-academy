Required reading

Mandatory before building

  • os package — Args; Open; File.Close; Exit. Handle the command boundary and own file lifetimes.
  • io package — Reader; ReadAll; LimitReader; Writer. Read at most limit+1 bytes and detect a real limit breach.
  • bufio package — Scanner; Scanner.Buffer; Scanner.Err; ScanLines. Avoid Scanner's default token ceiling and understand CRLF treatment.

Recommended while building

  • strings package — Split; TrimSuffix; NewReader. Manipulate line endings without trimming meaningful data.

Reuse and readiness

Finish these builds first: P01 · Go Field Notebook.

Reading is preparation. Be ready to explain the invariant you will test before implementing it.
