Start safely

Extract into a new folder. Open the module directory before running commands; nested modules do not participate in the hub's own test command. Preserve the supplied data contracts unless your guide explicitly allows a change. Replace ErrTODO paths with validated behavior; do not suppress errors merely to make tests green.
