CHAPTER 7 OF 14

Draw a static scene

Build reusable, bounded pixel primitives.

Before writing code

  1. Which layer should be drawn first so ants remain visible?
  2. Can drawing a thick disc cross image bounds?

Build in small passes

  1. Implement tested line and disc primitives.
  2. Render the stable tunnel/room background.
  3. Draw ants on independent copied frames and export PNG keyframes.

A grounded hint

Use a small hand-inspected 16×16 test image to check endpoints, clipping and radii. A large attractive scene can hide off-by-one pixel errors.

Trace and self-check

Draw a horizontal tunnel behind two rooms and an ant. The ant color must remain visible after every layer is drawn.

Exit gate

PNG dimensions, selected expected pixels and frame independence are tested.
