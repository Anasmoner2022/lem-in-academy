CHAPTER 4 OF 14

Full specification

  1. Implement a deterministic fit transform into a default 320×240 image with 20-pixel padding. Accept signed coordinates, preserve aspect ratio, center zero-span axes and reject invalid dimensions or nonfinite derived values.
  2. Draw tunnels as clipped or bounds-checked line segments, rooms as fixed-radius discs and ant positions as distinct high-contrast discs. Draw in stable edge, room and ant order.
  3. Use only image, image/color, image/draw, image/png, image/gif and other standard packages. Do not add golang.org/x/image/font, GUI libraries or browser JavaScript.
  4. Room names may be arbitrary valid grammar names. Write a UTF-8 text legend mapping stable room IDs to names and coordinates. Numeric glyphs are an optional hand-built bitmap feature, not a third-party font requirement.
  5. Require at least two boundary snapshots with the same positive number of positions and valid image coordinates. Render full independent paletted frames. Add four interpolation frames between supplied turn boundaries, using linear interpolation for moving ants and fixed positions for waiting ants. The final keyframe must match the next boundary exactly.
  6. Default per-turn time is 40 hundredths of a second; distribute it into four equal delays. Add initial/final holds of 40 units. Specify GIF LoopCount=0 and a disposal strategy that avoids trails.
  7. Maximum dimensions 1280×720, at most 2000 frames and 50000000 total stored pixels. Preflight checked width×height×frameCount; report a resource error before allocating beyond the budget. Never silently crop frames or omit turns.
  8. The CLI reads the supplied JSON dot sequence and writes studio.gif, first.png, last.png and legend.txt in the current directory only after validating the request. Fail cleanly on output errors.
